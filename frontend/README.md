# DrinkDuel frontend

Angular 22 standalone skeleton with routing, SCSS, strict TypeScript, and strict template checks. The root component contains only a router outlet; no screens or theme are implemented.

From this directory, run `npm ci`, `npm start`, or `npm run build`.

The CLI is installed locally. See the [project README](../README.md) for prerequisites and certificate settings, and [project scope](../docs/project-scope.md) for future design constraints.
